# OS Réclamations

Outil de gestion des réclamations clients (conformité ACPR) pour OS et Presence Management (avis Google).

## Structure

- `client/` — React + Vite + TypeScript
- `server/` — Node + Express + TypeScript

## Démarrage

```bash
# Client
cd client && npm install && npm run dev

# Serveur
cd server && npm install && npm run dev
```
